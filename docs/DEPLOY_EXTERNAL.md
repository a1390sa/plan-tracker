# نسخة مستقلة لجهة خارجية — دليل النشر والتشغيل

> هذا دليل نشر **نسخة معزولة تماماً** من نظام متابعة تنفيذ الخطط لأي جهة جديدة،
> منفصلة كلياً عن أي نسخة أخرى (قاعدة بيانات مستقلة، نشر مستقل، مستخدمون مستقلون،
> بلا أي اطّلاع من الجهات الأخرى على بيانات هذه النسخة). الشيفرة نفسها في هذا
> المستودع — الفرق فقط في حسابات Supabase وVercel وResend المستخدَمة، وهي بحسابات
> الجهة نفسها لا حساب من أعدّ لها النسخة، لضمان استقلاليتها الكاملة من اليوم الأول.

**التكلفة الشهرية: صفر** ضمن الخطط المجانية (Supabase + Vercel + Resend)، طالما
الاستخدام معقولاً (أقل من حدود الخطط المجانية).

---

## الخطوة 1: قاعدة بيانات مستقلة (Supabase) — 10 دقائق

1. أنشئ حساب Supabase خاصاً بالجهة (إذا ما عنده أصلاً)، ثم **مشروع جديد**. اختر
   منطقة قريبة جغرافياً (مثل Frankfurt للشرق الأوسط).
2. من **SQL Editor > New query** الصق محتوى `supabase/schema.sql` كاملاً ثم **Run**.
3. في استعلام جديد الصق محتوى `supabase/admin_policy.sql` ثم **Run** — هذه الصلاحية
   لازمة حتى يقدر مدير النظام لاحقاً يرقّي/يدير حسابات الموظفين من تبويب الإعدادات.
4. من **Authentication > Sign In / Providers** تأكد أن Email مفعّل.
5. من **Settings > API** انسخ `Project URL` و**Publishable key** (يبدأ بصيغة
   `sb_publishable_...`).

## الخطوة 2: البريد (Resend) — 5 دقائق

1. أنشئ حساباً في resend.com ومن **API Keys** أنشئ مفتاحاً.
2. (اختياري لاحقاً) وثّق نطاق الجهة لإرسال الرسائل باسمها؛ إلى حينه يعمل الإرسال
   من `onboarding@resend.dev`.

## الخطوة 3: وظيفة التنبيهات اليومية — 10 دقائق

من جهاز فيه Node.js مثبّت (nodejs.org):

```bash
npm install -g supabase
supabase login
cd plan-tracker
supabase link --project-ref <معرف المشروع من General settings>
supabase secrets set RESEND_API_KEY=<مفتاح Resend>
supabase secrets set MAIL_FROM=onboarding@resend.dev
supabase secrets set APP_URL=<رابط النشر بعد الخطوة 4>
supabase functions deploy send-notifications --no-verify-jwt
```

ثم الجدولة اليومية من **SQL Editor** (استبدل YOUR_PROJECT_REF بمعرّف المشروع):

```sql
select cron.schedule(
  'daily-notifications', '0 3 * * *',
  $$ select net.http_post(
       url := 'https://YOUR_PROJECT_REF.supabase.co/functions/v1/send-notifications',
       headers := '{"Content-Type": "application/json"}'::jsonb
     ) $$
);
```

(فعّل `pg_cron` و`pg_net` من Database > Extensions إن ظهرت رسالة عن امتداد غير مفعّل.)

## الخطوة 4: نشر الواجهة (Vercel) — 10 دقائق

1. أنشئ حساب Vercel خاصاً بالجهة، واستورد **هذا المستودع نفسه** (أو نسخة منه على
   حسابهم في GitHub) كمشروع جديد مستقل.
2. في **Environment Variables** أضف:
   - `VITE_SUPABASE_URL` = رابط مشروع Supabase الخاص بالجهة
   - `VITE_SUPABASE_ANON_KEY` = المفتاح العلني (Publishable key) لمشروعهم
3. اضغط **Deploy**. الرابط الناتج هو نظامهم المستقل.
4. ارجع لـ Supabase > **Authentication > URL Configuration** وضع رابط Vercel هذا في
   Site URL وRedirect URLs (مع `/**`).

## الخطوة 5: التشغيل الأول — 5 دقائق

1. يُنشئ أول مستخدم (مدير النظام عندهم) حسابه من رابط النظام نفسه مباشرة — **وليس**
   من لوحة Supabase، وإلا لن يُنشأ ملفه الشخصي وستفشل عمليات الصلاحيات (RLS).
2. اجعل هذا الحساب «مدير نظام»: Supabase > **Table Editor** > `profiles` >
   `is_admin = true`.
3. ارفع القالب الابتدائي الفارغ: `templates/نموذج_خطة_ابتدائي.xlsx` — مؤشر واحد
   تجريبي بـ12 مهمة (واحدة لكل شهر)، يُقبل مباشرة بلا أي تحذير.
4. بعد الرفع، من تبويب **«إدارة الخطة»** (ظاهر لمدير الخطة فقط) عدّلوا كل شي حسب
   خطتهم الفعلية مباشرة من داخل النظام — بلا حاجة للرجوع لملف إكسل مرة أخرى:
   - أعيدوا تسمية المؤشر التجريبي أو احذفوه وأضيفوا مؤشراتهم الحقيقية.
   - عدّلوا نص كل مهمة، أو احذفوها، أو أضيفوا مهاماً جديدة بأي شهر.
   - عدّلوا المستهدف الكلي لكل مؤشر ليطابق عدد مهامه الفعلي.
5. أضيفوا الموظفين من تبويب **الأعضاء** ببريدهم، وأسندوا لكل مهمة مسؤولاً رئيساً
   (إلزامي لدخول دورة التنبيهات) ومساندين عند الحاجة من **لوحة المتابعة**.

## لماذا قالب ابتدائي فارغ بدل ملف إكسل جاهز؟

محلّل الإكسل يتوقع بنية عمودية محدّدة (عمود «المؤشر»، «المستهدف»، «التنفيذ»،
وأعمدة أشهر)، وأي اختلاف بمسمّيات الأعمدة أو ترتيبها يرفض الملف أو يفسّره خطأً.
بدل تعليم كل جهة جديدة تفاصيل هذا القالب، القالب الابتدائي يُرفع **مرة واحدة فقط**
بنجاح مضمون، وكل التخصيص الفعلي بعدها يصير من واجهة النظام نفسها — بلا أي تعارض
أو حاجة لفهم بنية الإكسل إطلاقاً.
